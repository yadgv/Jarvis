# Jarvis eyes (browser extension)

Lets Jarvis read the page you're looking at: its address, its text, what you've
selected, and (when you ask) its code. It only talks to Jarvis on your own PC
(127.0.0.1); nothing is sent anywhere else.

Install once, in Chrome or Edge:

1. Open `chrome://extensions` (Edge: `edge://extensions`).
2. Turn on **Developer mode**.
3. Click **Load unpacked** and pick this `browser_extension` folder.

Jarvis must be running for it to work.
